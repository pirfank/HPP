About the Project

Bengaluru Home Price Predictor

This application uses a machine-learning regression model trained on Bengaluru housing data to estimate property prices based on location, area, BHK, and number of bathrooms.

The result is an estimate, not an appraisal. Actual property prices can vary based on factors such as property condition, exact location, amenities, age of the building, and current market conditions.
